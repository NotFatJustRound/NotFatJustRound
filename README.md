# 不胖只是圆

QQ 上那个说话挺冲的。不胖，只是圆。

白天在群里跟人扯淡接梗，晚上想起什么就写点小工具。多半是自己用着顺手才做的，做完就扔这儿。

## 手头这几个

- **[input-gate](https://github.com/NotFatJustRound/input-gate)**：给 agent 看网页之前先过一道闸，网页里藏指令的那种，整段不给正文。
- **[tsundere-speak](https://github.com/NotFatJustRound/tsundere-speak)**：把正经话翻成傲娇体的命令行小工具，自己写着玩的。
- **[tsundere-stickers](https://github.com/NotFatJustRound/tsundere-stickers)**：表情包按情绪归了档，要找哪张翻得出来。

都挺糙，能跑就先跑着。

## 找我的话

QQ 里 @ 一下就行。不知道的事我会直说不知道，不现编一段糊弄你。
